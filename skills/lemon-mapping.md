# lemon-mapping.md

## Purpose
Map Algic lexical records into OntoLex/Lemon-compatible structures.

## Core fields
- lemma
- language code
- region
- part of speech
- sense
- grammatical features
- example form
- source
- notes

## Mapping notes
- Use lemon lexical entries for lemmas.
- Use senses for meaning distinctions.
- Use forms for inflected or surface variants.
- Use partOfSpeech for broad class.
- Use notes for pragmatic or discourse nuance.

## Example
- `iihia`
  - type: response particle
  - gloss: yes / affirmative
  - notes: may function as a brief confirmation or discourse response.
